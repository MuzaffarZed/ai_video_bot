### 1-Usul: Telegram Bot sifatida ishlatish

1. Telegramda [@BotFather](https://t.me/BotFather) ga kiring va yangi bot ochib tokenini oling.
2. Loyiha ichidagi `.env` (yoki `config.py`) fayliga bot tokenini yozing:
   ```env
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```
3. Botni ishga tushiring:
   - `start_bot.bat` faylini ikki marta bosing, yoki terminalda:
   ```bash
   C:\Users\MuzaffarZed\ai_workspace\venv\Scripts\python.exe bot.py
   ```
4. Telegramda botingizga kiring va `/start` bosing!
